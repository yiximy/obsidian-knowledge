# Claude Code Instructions

Follow `AGENTS.md` in this repository.

For saving, updating, querying, and organizing knowledge points, use the Agent Skill:

```text
skills/obsidian-knowledge-workflow/SKILL.md
```

Quick rules:

- Search `Knowledge/Problems` before creating a new note.
- Update existing notes instead of duplicating them.
- Save scripts under `Knowledge/Scripts/<problem-id>/` and register them in the note's `scripts` property.
- Save resources under `Knowledge/Resources/` with `type: resource`.
- Use `Knowledge/Home.md` as the entry point.
